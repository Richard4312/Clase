- En clase con cmd

node -v

## Verificar si tenemos npm

https://www.npmjs.com/package/five-server

npm -v

## Insalar pnpm

https://pnpm.io/es/

npm i -g pnpm

pn -v

- pn init

## Configurar Scripts

"dev": "five-server"

## Insatalar Five-Server

pn add nombre-paquete  (five-server en este caso)
